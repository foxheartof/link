# 🦊 FoxHeart | Acceso a información y boletos

Micrositio de acceso directo al sitio oficial de **FoxHeart**. Su objetivo es ofrecer a los visitantes una ruta sencilla para consultar la información disponible y encontrar las opciones de compra desde una única página.

## 🔗 Enlace único

**[Ver información y comprar boletos](https://foxheartof.github.io/)**

La página muestra exclusivamente este botón, que abre el sitio de FoxHeart en la misma pestaña. No hay formularios, pagos, menús ni contenido adicional.

## ✨ Características

- Diseño responsive, adaptable a móviles y computadoras.
- Identidad visual basada en tonos oscuros, rosa y dorado.
- HTML y CSS estáticos, sin JavaScript ni dependencias.
- Sin recopilación de datos ni procesamiento de pagos.
- Compatible con GitHub Pages.

## 🚀 Publicar en GitHub Pages

1. Sube los archivos a la raíz de la rama `main` de tu repositorio.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona `main` y `/(root)`; después, guarda los cambios.
